101.2 Boot the system
boot has 5 general steps:
1. motherboard firmware does POST(Power On Self Test)
2. motherboard loads bootloader
3. bootloader loads kernel(linux) based on it's config
4. kernel prepare and load root file system and initialization program.
5. init program starts services.

bootloader
bootloader initializes the minimum hardware needed for running the system then locates and runs os.

kernel
kernel is core of operating system. bootloader loads kernel in the memory and runs it. kernel needs some initial info to start like derivers and .... those stored in "initrd" and "initramfs". kernel is able to control to passing parameters by grub. for example : send "1" or "S" => system booting on single core mode.

dmesg
linux will show booting logs only we need to press "Esc" while booting. After that system booted syslog daemon stores those logs in "/var/log/dmesg".
we can see them with "dmesg" command but in better way we use "journalctl -k" to see kernel logs and "journalctl -b" to see bootloader log.

var/log/messages
After the init process comes up, syslog daemon will log messages.

init
after that kernel fully running now time for init daemon to start other services and daemon and programs.
